# F06: Creator content pilot and toolkit

Status: **manual validation first; software gate not yet met**.

## Outcome

Help a basketball creator turn one matchup or tournament into publishable,
original content faster. Establish willingness to pay before building a creator
dashboard.

## Phase A: manual paid pilot

After F00 clears the intended commercial use:

1. Produce three representative content packages from existing output.
2. Contact 30 creators with a personalized sample tied to their audience.
3. Offer a defined pilot: four weekly packages for `$99` or another owner-
   approved test price.
4. Deliver manually and record time spent, revisions, assets used, publishing
   result, and repeat request.
5. Ask which step saved time or created value. General praise is not evidence.

Each package may contain:

- result and title-odds graphics using original visuals;
- key season-stat comparisons and limitations;
- a 60-second and a longer script draft;
- poll and caption copy;
- follow-up matchup suggestions;
- a stable audience interaction link.

Every factual statement must be traceable to exported data or approved product
copy. Scripts must not invent player performance, quotations, game scores, or
causal explanations the model cannot support.

## Software gate

Build the toolkit only when the creator-product gate in `HANDOFF.md` is met:
two paid pilots, one repeat purchase/renewal, and a repeated production step.

## Candidate Phase B surface

- saved creator brand kit using original/non-infringing assets;
- batch matchup/tournament selection;
- editable copy templates grounded in structured inputs;
- 1200x630, portrait, square, and transparent-background exports;
- package history and duplicate/version controls;
- audience link and engagement summary;
- explicit commercial export entitlement supplied by F07.

The first software release automates only the repeated paid step identified in
Phase A.

## Completion criteria

### Phase A

- Outreach, reply, call, paid pilot, and renewal counts are recorded.
- At least one creator publishes a package or explains why they did not.
- Delivery time and revision count establish the real cost of service.
- A go/no-go decision names the repeated workflow, payer, price, and evidence.

### Phase B

- A creator can generate the validated package without staff intervention.
- Exports remain grounded in structured model/data fields and carry required
  limitations/attribution.
- Brand assets are isolated per account and are not used without authorization.
- Tests cover each export size and entitlement boundary.
