# Court of All Time

Cross-era NBA matchups: [courtofalltime.win](https://courtofalltime.win) estimates who would win between team-seasons
from 1985–86 on, from each team's season stats measured against its own league.

- **Ask the Court**, a grounded question-answering (RAG) system over the site's data, with its evaluation:
  [`docs/rag/README.md`](docs/rag/README.md).
